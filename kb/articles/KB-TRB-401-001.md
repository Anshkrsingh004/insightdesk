# Fix CF-401 authentication errors

_CloudFlow help center · Troubleshooting · applies to all_

## Overview
This article explains how to rotate the API token and re-authenticate in CloudFlow.

## Steps
1. Open **Settings → API tokens**.
2. Follow the on-screen prompts to rotate the API token and re-authenticate.
3. Save your changes and verify the result.

## Notes
- Available on all. If you are on an older version, some menus may differ — see
  KB-ADV-VERSIONS-001.
