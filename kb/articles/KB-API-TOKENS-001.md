# API authentication and tokens

_CloudFlow help center · API & integrations · applies to all_

## Overview
This article explains how to create a Bearer token and authenticate API calls in CloudFlow.

## Steps
1. Open **Settings → API tokens**.
2. Follow the on-screen prompts to create a Bearer token and authenticate API calls.
3. Save your changes and verify the result.

## Notes
- Available on all. If you are on an older version, some menus may differ — see
  KB-ADV-VERSIONS-001.
