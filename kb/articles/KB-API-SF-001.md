# Salesforce connector setup

_CloudFlow help center · API & integrations · applies to 4.x_

## Overview
This article explains how to authorise Salesforce via OAuth and map objects in CloudFlow.

## Steps
1. Open **Settings → Connectors**.
2. Follow the on-screen prompts to authorise Salesforce via OAuth and map objects.
3. Save your changes and verify the result.

## Notes
- Available on 4.x. If you are on an older version, some menus may differ — see
  KB-ADV-VERSIONS-001.
